# Listens Project 🎧

Простой Laravel-проект с реализацией событий (Events) и слушателей (Listeners).

## 📦 Стек технологий
- PHP 8.1+
- Laravel 10
- Events & Listeners
- Notifications

## 🚀 Установка

```bash
git clone https://github.com/MaxGot69/listens-project.git
cd listens-project
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
